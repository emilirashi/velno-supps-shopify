# Velno Supps - Premium Health Supplements Store

A modern Shopify store for premium health supplements, built with a clean, professional design inspired by industry-leading supplement retailers.

## Store Structure

### Key Features
- Product catalog with detailed descriptions
- High-quality product images
- Customer reviews and ratings
- Blog/educational content
- Subscription management
- Mobile-responsive design

### Directory Structure
```
/shopify
  /theme          - Liquid theme files
  /products       - Product data
  /collections    - Collection organization
  /pages          - Static pages
  /blogs          - Blog content
  /assets         - Images, CSS, JS
```

## Getting Started

1. Connect this repository to your Shopify store
2. Customize products with your own details
3. Update branding and styling
4. Configure payment gateway
5. Set up shipping zones

## Store Sections

- **Shop** - Full product catalog
- **Best Sellers** - Featured products
- **Support** - Customer service links
- **Blog** - Educational content about supplements
- **Account** - Customer account management
- **Cart** - Shopping cart functionality

---

For customization or deployment questions, refer to the Shopify CLI documentation.
